## Regole di versionamento

- Ogni modifica a un prompt passa da una *pull request* e si annota nel `CHANGELOG.md` del personaggio.
- Dal **23/11/2026** (release **v1.0.0**) prompt e knowledge base sono **congelati** fino alla fine dell'ultimo incontro (3/12): ogni partecipante parla con la stessa versione degli agenti. Le correzioni urgenti si registrano come deviazioni dal protocollo in `docs/registro-decisioni.md`.
